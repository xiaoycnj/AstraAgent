## 自动化结果

- `tests/browser_design.cjs` 覆盖分层设置、顶层弹窗下拉、隐藏无效字段展开、焦点恢复、路由字段显隐、键盘命令、停止确认、会话隔离、配色测量、七种视口与强制颜色。
- `tests/browser_ui.cjs` 覆盖共享组件、固定设置标题、六种宽度、三种语言、窄窗口分类和应用菜单、弹窗固定操作区、服务商列表刷新后的焦点返回、分类搜索键盘与能力页签。
- `tests/browser_models.cjs` 覆盖模型规格回填、手动覆盖、待提交模型保存、异步过期响应与路由预览。
- `tests/browser_security.cjs` 覆盖既有浏览器关键路径、Markdown/LaTeX、流式 DOM 复用、恢复流程与 CSP。已有本地市场插件会被保留，避免测试覆盖用户安装。
- `tests/test_usage_meter.py` 验证按任务聚合、缺失用量、重放去重与统计数据库失败降级。
- Python 完整回归为 239 项通过。设计、模型、共享界面和既有浏览器回归通过，未观察到页面脚本错误或 CSP 违规。

测试输出和截图位于开发工作目录 `work/design-evidence.json`、`work/design-task-*.png`、`work/design-settings-*.png`、`work/ui-system-evidence.json`、`work/ui-*.png`。发行包附带规范文档，工作目录证据与私人运行数据不打包。

## 本轮视觉核对

深浅色截图覆盖对话、服务商、个人资料、插件管理、资料库、生图与定时任务页面。320 CSS px 窄窗口的设置分类和应用菜单保持横向标签，正文与内容区域独立滚动。服务商弹窗在 800 px 高度下保留可见的保存操作，基础信息、高级参数和规格各自分组。

默认保留玻璃导航和艺术背景，正文与输入采用稳定表面。自定义皮肤通过正式声明式入口验证圆角和颜色覆盖。热力图继续保留 12 px 方格，粗指针模式通过已有专项回归检查。

本轮没有启动用户的主窗口，原生 DPI、多屏、系统缩放动画和实际读屏播报仍按上表列为待验证项。
