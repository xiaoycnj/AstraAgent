# AstraAgent 产品路线图 · 2026-11-20

目标是让用户从「找到上次做的事」顺畅地过渡到「继续执行、检查并取走成果」。优先打通已有的会话、项目、附件和任务恢复。新功能复用现有入口，避免继续挤占主侧栏。

## 竞品功能与交互

调研依据为官方说明、公开仓库截图与产品演示。交互列记录资料中能看到的设计，未进行逐款实机性能、可访问性评分。AstraAgent 取舍列为产品判断。

| 参考产品 | 官方资料显示的功能和 UI | AstraAgent 的取舍 |
|---|---|---|
| Claude Projects | 项目知识、项目指令、项目内会话。项目空间汇集文件与聊天历史。[官方文档](https://support.claude.com/en/articles/9517075-what-are-projects) | 页眉显示当前任务所属项目、可用资料和上下文范围。把「侧栏项目组」与「模型可访问的项目」区分开。 |
| VS Code Copilot | 通过会话列表查看运行状态、执行方式和文件改动，切换归档筛选。会话可在并排布局查看。[官方文档](https://code.visualstudio.com/docs/copilot/chat/chat-sessions) | 列表优先显示状态和续接入口，详细日志仍在现有执行记录中展开。 |
| Cherry Studio | 多供应商、助手和对话内模型对比。公开截图分别展示对话、供应商设置和创作工作区，文档还列出标签页与独立窗口。[官方仓库](https://github.com/CherryHQ/cherry-studio) | 供应商与模型身份放在同一个可见位置。调试数据留在现有性能统计页。 |
| Open WebUI | 主项目将离线自托管和兼容本地、云端模型作为核心，公开项目页提供应用界面预览。[官方仓库](https://github.com/open-webui/open-webui) | 把本地搜索与外发给服务商的动作区分清楚，统一各主题下的搜索入口与无结果提示。 |
| Obsidian Canvas | 卡片、文件嵌入、分组和可标注连线，画布演示展示这些元素如何共用一个空间。[官方演示](https://obsidian.md/canvas) | 会话、文件和任务节点链接回已有记录。优先实现可追溯引用、键盘操作和缩放后的可读性。 |

## 阶段和验收

| 阶段 | 任务 | 验收目标 | 状态 |
|---|---|---|---|
| P0 · 会话查找与交付 | 合并标题、项目组和 Chat / Agent 模式查找，覆盖归档与窄窗入口。稳定刷新及插件重载后的浏览器回归。 | 可从命令面板和「更多」唤出搜索。从多个字段组合条件可定位唯一会话。清空条件恢复原有分组折叠状态。标准版和 Lite 均生成校验文件。 | 本轮 |
| P1 · 本地搜索与项目范围 | 实现正文片段与跳转定位。项目页增加当前上下文摘要及资料来源。 | 归档可显式包含，删除后同步移除索引。搜索无需模型或网络。用 1 万条测试消息记录查询耗时；确认新增内容可命中、已删除内容不可命中。 | 待排期，依赖 P0 |
| P2 · 任务续接与成果 | 在会话历史显示运行、待确认、可继续、结束状态。在现有审查面板集中显示成果、来源和验收结果。 | 在运行中切换会话能返回同一任务。停止后状态不回跳，续接不会重复已保存步骤。附件可预览和下载，失败能定位到具体阶段。 | 待排期，依赖 P0 |
| P3 · 画布与可自定义布局 | 增加会话、任务、文件引用节点与有名称的连线。统一调色、间距和快捷键。 | 重开画布可跳回源记录。节点移动、连线、删除均能撤销。验证窄窗、亮暗色、键盘操作和减少动效。 | 待排期，依赖 P1、P2 |

## 本轮交互决策

- 活跃列表通过「更多 → 搜索与筛选」、会话栏的搜索按钮或命令面板进入。查询按空白分词，所有词都要命中，可跨标题、项目组、模式组合。例如 `发布组 Chat release`。单独的项目组筛选可与搜索叠加。
- 搜索复用已加载的会话列表。归档在归档页面搜索，正文和附件不在本轮范围内。搜索期间展开匹配的分组，关闭筛选时清空条件并恢复分组折叠状态。
- 发布以本地 Windows 浏览器回归、发行包测试和 SHA-256 校验为基础。GitHub Actions 的结果单独核实。Windows 原生窗口与辅助技术实机验收属于后续验证。
