# 智能交互界面

AstraAgent 的 IUI 参考 OpenAI 发布的 GPT-6 Intelligent UI 交互方式，使用本项目的原生组件渲染器与 `render_iui` 模型工具实现。比较、任务拆解、学习测验和参数计算等场景可以生成可操作的界面。简单问题继续使用文字回答。

模型服务需要支持 function calling。聊天默认启用 IUI，可在设置的常规页面关闭。普通 Tools 的文件、命令和网络权限保持原有授权流程。IUI 工具只创建当前会话中的受限组件文档。

## 组件与交互

- 文字、指标和比较卡片。
- 带搜索和列排序的数据表格。
- 支持正负数、序列显示开关和数值文本的条形图。
- 待办清单、单选方案和带反馈的选择题。
- 文本、数值、滑杆、选择器、复选框与计算结果组成的表单。

模型决定何时调用工具，应用在聊天中即时呈现结果。组件正文按纯文本显示。工具返回的标记保存在助手消息中，刷新后自动恢复。

清单、选项与表单值保存在本机会话数据库。输入变化会自动保存，失败后保留待保存内容并提供重试。状态修改使用 revision 比较，另一窗口先修改时会读取新版本，再重试当前字段的补丁。相同字段以最后成功写入的值为准。

用户点击“将结果加入输入框”后，当前选择与计算结果会追加到现有草稿中。发送仍由用户操作。会话分支复制组件和状态，后续修改分别保存。删除会话会级联删除所属组件。

## 模型调用示例

```json
{
  "title": "时间规划",
  "description": "调整每天的投入时间，估算完成天数。",
  "blocks": [
    {
      "id": "estimate",
      "type": "form",
      "title": "估算",
      "fields": [
        {"id": "total", "type": "number", "label": "总工时", "min": 1, "max": 1000, "default": 24},
        {"id": "daily", "type": "range", "label": "每天工时", "min": 1, "max": 8, "default": 2}
      ],
      "outputs": [{"label": "预计天数", "expression": "total / daily", "unit": "天"}]
    }
  ]
}
```

工具返回 `iui_id` 与 `[[iui:32位标识]]`。应用自动补齐消息标记。更新已有组件时提供 `id`，使用稳定的组件和字段 ID 保留兼容状态。

表单计算支持数值字段、括号、四则运算、余数、有限指数与 `min/max/abs/round/sqrt/sin/cos/log`。后端先遍历验证完整 AST，再计算。非法表达式、数值越界与跨会话读写会被拒绝，计算错误显示待补全提示。

文档最多 24 个组件、256 KB。表格最多 100 行和 12 列，图表最多 40 个分类和 6 个序列，表单最多 16 个字段与 8 个结果。组件文档不运行模型提供的 HTML、JavaScript、外部资源或网络请求。

## 设计与验证

采用原生语义控件、可见焦点、字段标签、单选分组、表格标题和排序状态、保存状态播报。图表同时显示序列名称和数值。窄窗口按列重排，长表格在自身区域滚动。浅色和深色沿用应用设计令牌，字体使用系统字体栈。清单保留复选框语义。

自动回归覆盖正常聊天入口的工具调用、流式标记、计算、键盘滑杆、选择反馈、表格排序筛选、图表开关、刷新、冲突、断网恢复、会话隔离、分支复制与窄窗口。当前检查未包含完整屏幕阅读器人工验收。

交互依据来自 OpenAI IUI 说明、WCAG 2.2 和 Fluent 2 字体规范。[OpenAI IUI](https://help.openai.com/en/articles/20001598-intelligent-ui-in-chatgpt)、[WCAG 2.2](https://www.w3.org/WAI/WCAG22/quickref/)、[Fluent 2 Typography](https://fluent2.microsoft.design/typography)
