# 媒体插件、模型规格与自动路由

## 配置服务商和模型

设置的服务商页面分为对话、图片、视频、多模态四组。同一服务商可声明多项能力。视频分组支持地址、密钥和模型管理，当前执行链路提供对话与图片协议。

每个模型支持编辑上下文窗口、输入/输出/缓存读取价格、币种、图片输入能力、工具调用能力、推理能力、推理档位、输出上限、模型用途、路由等级和自动路由开关。价格单位为每百万 Token。空白字段优先使用匹配到的参考规格，仍无参考值时保持未知，零表示用户配置的零单价。

点击“内置模型库”导入离线记录，也可手动添加。当前快照来自 Models.dev，覆盖 OpenAI、Anthropic、DeepSeek、GLM、Qwen、Kimi、MiniMax、MiMo、Gemini、LongCat、StepFun 和 Seed，共 15 个服务商（含区域接口）与 319 条记录。StepTap 在本版按 StepFun（阶跃星辰）处理。

输入模型 ID、从接口拉取列表、重新编辑已有服务商时会自动补全参考规格。官方域名或明确选择的“规格参考厂商”优先匹配。中转接口使用精确 ID 检索离线数据库，结果唯一或各项参考规格一致时可自动填入。同名规格存在差异时提示选择参考厂商，未知 ID 支持手动填写。

已保存的手动规格、零单价、关闭能力与自定义名称优先保留。更换模型 ID 会清理前一个型号自动填入的字段，切回原 ID 时恢复原有规格。点击“使用参考规格”可以主动重新应用参考值。保存服务商会同时提交输入区内的模型条目。拉取列表或匹配过程中切换服务商、修改 ID 时，过期响应会被丢弃。

参考厂商承担规格匹配，接口地址、鉴权与请求协议由服务商配置控制。执行时输出预算受模型输出上限与上下文预算约束，推理请求按已配置的支持档位映射。普通模型的已知非推理能力会阻止发送推理参数。

来源、快照时间与摘要保存在 `web/assets/models/registry.json`。模型等级是本地路由预设，可编辑调整。参考价格需与实际服务商核对。Models.dev 的 MIT 声明可在“关于”的开源声明弹窗查看。[数据源与许可证](https://github.com/anomalyco/models.dev)

## 图片插件

在对话中通过 `@` 加载“图片生成”插件，或由允许 Tools 的 AutoModelReview 图片任务加载。插件提供 `list_image_models`、`image_gen`，保留 `generate_image` 兼容入口。全局关闭的插件仍需在设置中启用。

主模型可以读取用户需求、润色提示词，再调用下面的参数。

```json
{
  "provider": "已配置的图片服务商 ID",
  "model": "image2.5",
  "size": "1024x1024",
  "prompt": "经过润色并保留用户约束的提示词",
  "file": "当前会话的图片附件 ID",
  "quality": "high"
}
```

`model` 需在服务商模型目录中配置。省略服务商时，插件按模型 ID 匹配可用图片服务商。`file` 为单图，`files` 支持最多四张图，总计最多 10 MB，接受附件 ID 或应用内附件路径。文件路径和远程 URL 均不可作为参考图参数。

没有参考图时使用 OpenAI 兼容 `/images/generations` JSON 请求，有参考图时使用 `/images/edits` multipart 请求。尺寸接受 `1024*1024` 和 `1024x1024`，可传 `quality` 与 `background`，最终取值需服务商支持。参数示例中的 image2.5 是用户可配置的模型 ID。

插件只读取当前会话来源、产物或本轮用户上传的图片，并沿用权限确认、取消、模块开关与下载安全检查。生成图片进入会话产物和资料库。显式标为仅文本的对话模型收到附件说明与 ID，图片原始字节可经已批准的图片工具转发。[编辑协议参考](https://developers.openai.com/api/reference/resources/images/methods/edit)

## 上下文与费用

配置模型窗口后，自动压缩按本地 Token 估计量触发，预留输出空间和安全余量。图片使用独立预算估计，避免把 Base64 当作正文长度。没有窗口配置的旧模型继续使用常规字符阈值。

用量页使用服务商上报的 Token 数与调用当时的价格快照估算费用。缓存读取可单独定价，不同币种分开合计。缺少价格或用量的调用显示为未计价。当前按基础输入输出单价估算，阶梯价格、附加费用、汇率、税费与服务商账单可能存在差异。

## AutoModelReview

在模型列表选择 `AutoModelReview` 后，滑块切换为“最低模型强度”，提供标准、高级、旗舰三档。选择具体模型后恢复普通思考强度滑块。

在服务商设置上方的 Auto Model Review 配置中选择规则路由或 AI 路由。

- 规则路由根据任务、图片和工具需求筛选已配置的模型。
- AI 路由将任务文本与需求标记发送给指定 Judge，接收等级与推理强度 JSON，再由本地引擎筛选候选。Judge 不决定权限。额外调用会计入用量，失败时显示原因并使用规则。
- 策略包括综合推荐、质量优先、价格优先。价格排序只比较所选币种，其他币种视为未知报价，费用统计保持各币种分离。
- 视觉、工具、上下文与禁用状态参与硬性筛选。没有合适模型会返回配置提示。
- 用户的最低等级是硬约束。任务分析推荐的等级暂无候选时，路由在满足用户最低等级和能力要求的模型中降级选择并记录原因。
- “调度范围”即时保存在本地，默认覆盖全部已配置服务商，也可限制为当前对话服务商。当前选择为空时，“仅当前”表示默认接口。其他路由策略通过“保存路由设置”提交。
- “路由检查”按已保存配置展示候选、排除原因与规则结果，便于发现上下文缺失、能力未确认、禁用或范围限制。检查过程在本地执行，AI Judge 的实际判断仍在发送任务后运行。
- 手动选定具体模型时沿用手动选择。Auto 模式中的明确 `model=模型ID` 或“使用 模型ID”也优先处理，无法满足能力要求时返回说明。

任务中指定的图片或视频型号交给对应媒体工具处理，主对话模型从对话候选中选择。预览中的显式模型选择与实际执行采用同一优先规则。

Judge 在执行工作线程中运行，可通过停止按钮取消。路由完成后，实际服务商、模型、等级、推理参数和原因写入任务事件。执行检查点保存已确定的模型，恢复任务沿用该结果。

模型数据库仅提供元数据。当前原生协议适配覆盖 OpenAI Responses / Chat、Claude Messages 及现有 DeepSeek、GLM 专项链路，其他厂商可使用其 OpenAI 兼容接口。自动路由的等级与规则是可调整的本地策略，无法替代实际模型评测。

## 验证范围

本地模拟 HTTP / multipart / SSE、权限和浏览器回归验证调用链。尚未进行各厂商的付费图片或 Judge 线上验证。
