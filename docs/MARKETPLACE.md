# 扩展市场

从侧栏的“更多 → 扩展市场”进入，也可从插件管理或外观设置打开。目录带有离线副本，点击“刷新目录”从本项目 GitHub main 分支获取最新作品。安装的插件立即启用，之后可以在插件管理中关闭。

## 作品与投稿

目前目录包含 cnxiaoy 发布的 3 个行为插件及 4 款玻璃皮肤，均使用 MIT 许可证。市场展示作者、版本、许可证与内容摘要。社区作者可以导出 JSON 作品包，在“投稿作品”打开的 GitHub Issue 中附上作品和授权说明，维护者审核后合入目录。

插件使用应用已有的声明式生命周期事件。支持输入长度限制、提示前缀、回复归档、完成提醒和阅读布局。插件制作器生成的 schema_version 2 清单可包装为市场作品。皮肤使用受限颜色令牌、主题、模糊半径和圆角参数。JSON 包不执行脚本或任意 CSS。

## 作品包结构

作品为 schema_version 1 的 JSON 对象，包含 id、kind（plugin 或 skin）、name、description、author、license、version、payload 和 sha256。id 与 payload.id 相同，version 为 x.y.z。sha256 对 payload 使用 UTF-8、键名排序、无空格分隔符、保留 Unicode 的 JSON 序列化后计算。参见 marketplace/catalog.json 中的完整例子。

在市场点击“导出当前皮肤”生成可导入的作品包。作者信息和许可证可在提交前编辑。插件详情也可以导出作品包。更改 payload 后需要重新计算摘要。

SHA-256 用于检查内容是否变化，作者身份依赖目录审核及发布渠道。目录从固定官方 HTTPS 地址更新，更新失败保留旧缓存。不会接受作品中声明的远程脚本。

## 数据与恢复

安装记录与当前皮肤存于 data/marketplace/state.json，缓存目录存于 data/marketplace/catalog.json。皮肤预览仅临时改变界面，应用后保存。取消预览恢复预览前外观，“恢复原外观”恢复本浏览器首次应用市场皮肤前的外观。

插件安装到 plugins/<id>，同名本地插件受到保护。更新或卸载市场插件会将旧目录移到 plugins/.market-trash/<id>-<随机标识>，保留用户修改。运行中的窗口在下次刷新能力或重载时获取新插件状态。市场与插件管理共用同一启用开关。
