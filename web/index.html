WELCOME TO YOUR WORKSPACE

先了解，再开始。

AstraAgent 是本机运行的个人工作空间；连接模型后，选定的内容会发送到相应服务。

隐私说明

对话会发送给你配置的模型服务商，可能包括对话历史、提示词、附件、已启用的个人资料和记忆，以及项目背景。记忆仅在启用后作为上下文。语音请求会将文本或录音发送到你配置的语音服务。模型服务商可能按其政策处理数据；请勿提交不希望该服务处理的内容。

会话和工作空间数据保存在本机 data 目录，记忆保存在本机 memory 目录。配置中的 API 密钥在 Windows 上由当前用户 DPAPI 加密，但同一用户权限下的恶意程序仍可能访问数据。第三方扩展、MCP、项目验证器和宿主命令可按其权限访问文件或网络。我们不对第三方行为、服务商留存或模型输出作保证。

TERMS & RESPONSIBILITY

你来选择如何连接。

使用条款与风险确认

外部模型、语音及其他在线服务可能产生费用，其隐私、收费和数据保留条件由服务商决定，请自行核对。你需确认有权提交所选内容，并负责选择服务商、模型、扩展与命令。

“完全访问”权限可让宿主命令以当前 Windows 用户身份执行。权限审批能降低风险，但不能消除提示注入；应用不是操作系统级沙箱。安全审核会记录操作摘要，但不应视为不可篡改日志。此页为产品说明和风险确认，并非法律意见。
