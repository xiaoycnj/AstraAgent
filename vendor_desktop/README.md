# Desktop runtime

Windows x64 / Python 3.14 package.

pywebview 6.2.1, pythonnet 3.2.1, cffi 2.1.1, clr_loader 0.3.1, bottle 0.13.4, proxy_tools 0.1.0, typing_extensions 4.16.0, pycparser 3.12.

Original metadata and licenses are retained in the matching dist-info directories. The Standard release bundles its fixed WebView2 Runtime under runtimes/webview2. Lite uses the system-installed WebView2 Runtime and standard CPython 3.14 x64 (GIL enabled). Both editions retain these required desktop dependencies. The Windows .NET Framework remains an OS component.
