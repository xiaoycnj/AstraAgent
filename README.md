# AstraAgent — Personal Agent Workspace

个人智能体工作空间，提供 Windows 原生桌面、CLI 和浏览器界面。使用 Python、SQLite 与 WebView2，接入用户自行配置的 OpenAI 兼容模型服务。

[下载标准版 / Lite 版](https://github.com/xiaoycnj/AstraAgent/releases/latest) · [MIT License](LICENSE)

标准版内置完整运行环境，Lite 使用本机 CPython 3.14 x64 和系统 WebView2。Node.js/npm 仅在相关工具或 MCP 服务需要时由 Lite 用户安装。两版使用相同应用功能。

克隆源码后运行 `start.bat` 打开桌面或 `CLI.bat` 使用终端助手。源码中已包含必要的小型依赖，运行环境要求与 Lite 一致。测试命令为 `python.bat -m unittest discover -s tests -q`。标准版打包需从标准发行包取得 `runtimes` 环境，并保留源码中的 `runtimes/python` 配置文件。

## 开始使用

1. 将压缩包完整解压到可写的文件夹，不要直接在压缩包内运行。
2. 面向 Windows 10/11 x64。标准版内置 Python、Node.js/npm 与固定版 WebView2，Lite 复用本机环境。桌面宿主使用 Windows 系统的 .NET Framework 组件。
3. 双击 **启动.bat** 或 **start.bat**。显示原生启动画面，守护服务就绪后进入内嵌工作空间。
4. 点击左下角「接口与模型设置」，填写接口地址、API Key、模型名称，点击「测试连接」后保存。
5. 在「对话」中发送消息，或切换到「无限画布」。

默认本地通信地址为 http://127.0.0.1:8787。主窗口退出时会关闭它管理的后台服务。应用内“新窗口”可打开共享服务的独立工作窗口。

如果默认端口被其他程序占用，可运行：

```powershell
py -3 server.py --port 8788 --open
```

## API 接入

支持 OpenAI 兼容的 **Chat Completions** 接口：`POST {Base URL}/chat/completions`。

- Base URL 填服务商给出的基础地址，例如 `https://api.example.com/v1`。
- 也支持粘贴完整的 `/chat/completions` 地址，保存时会规范化。
- 模型名填写服务商提供的真实模型 ID；「获取列表」会请求 `/models`，不支持列表的服务商可以手动填写。
- API Key 由使用者自己提供。支持不需要密钥的本地服务。
- 「测试连接」会向选中的模型发一条简短请求，可能计入服务商用量。
- 普通对话支持流式返回与断线续读，接口超时可设置 10–180 秒。
- 不支持仅提供 Anthropic Messages 或 OpenAI Responses 格式而不兼容 Chat Completions 的端点。

首次启动也可以通过 `AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY` 环境变量预填。保存 GUI 设置后以本机配置文件为准。

## 已实现

### 多人格审查

在输入框上方打开「多人格审查」，选择 2–4 个并行视角：架构师、挑错者、用户视角、安全审查。模型并行给出各自意见，再由主持人格综合证据、分歧和建议。每条意见以独立角色消息保存，最终汇总单独标出。全流程使用当前配置的同一个模型；每次审查会发起所选人格数加一次汇总，共 3–5 次模型调用，服务商可能按调用计费。任一步失败时不保存半成品，原输入保留供重试。

### 外观

左下角可切换浅色和深色模式。偏好保存在当前浏览器中；对话、画布两种页面同步切换。

### 对话

新建、切换、重命名、删除会话；连续对话；复制回答；代码块显示；导出 Markdown。每次请求携带最近 40 条历史消息与系统提示词。请求失败时显示错误并保留输入。绑定项目的流式任务中断时，会保存已接收内容与中断原因，供检查和继续。消息长度上限 32000 字符，服务商仍有自己的上下文限制。

### 无限画布

- 多画布创建、切换、重命名、删除。
- 便签、文档、智能体三类节点；右侧编辑内容。
- 拖动节点、拖动空白处平移、滚轮缩放、适应视图。
- 点击「连线」，依次点击来源节点、目标节点；右侧可删除连线。
- 节点复制、删除、撤销、重做。
- 自动保存到本地 SQLite；Ctrl+S 可以手动重试保存。
- 导出和导入 JSON。
- 选中智能体后点击「执行任务」，会把当前任务及所有直接连入节点的文字发送给用户配置的模型；完成后新增文档节点，并保存对应对话。
- 多页面版本检查：冲突时拒绝覆盖。可先导出未保存内容，再刷新。

画布执行由用户触发。智能体工具、命令与文件访问由常规设置中的统一权限控制器管理。

## 数据与密钥

所有持久数据保存在项目的 `data/` 目录：

- `workspace.sqlite3`：会话、消息、画布。
- `settings.json`：模型配置与 API Key。密钥以本机文件形式保存，不加密；网页读取配置时只返回是否存在密钥，不回传密钥值。浅色/深色偏好保存在浏览器 localStorage。

分发程序时只分享干净的压缩包，**不要把自己的 data 目录打包**。备份数据前先停止应用，再复制整个 data 目录。程序只监听 127.0.0.1，面向本机单用户；不用于公网部署。

## 接口概要

先 `GET /api/bootstrap` 取得本次服务的 token，写请求携带 `X-App-Token` 与 `Content-Type: application/json`。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | /api/health | 健康状态与应用标识 |
| GET / PUT | /api/settings | 读取脱敏配置 / 保存配置 |
| POST | /api/settings/models | 获取模型列表，可传入未保存的配置 |
| POST | /api/settings/test | 测试模型调用，可传入未保存的配置 |
| GET / POST | /api/sessions | 会话列表 / 创建（title） |
| PATCH / DELETE | /api/sessions/{id} | 重命名（title）/ 删除 |
| GET | /api/sessions/{id}/messages | 消息历史 |
| POST | /api/sessions/{id}/chat | 对话（content） |
| POST | /api/sessions/{id}/review | 多人格审查（content、personas: 2–4 个人格 ID） |
| GET | /api/canvases | 画布列表 |
| GET / PUT / DELETE | /api/canvases/{id} | 读写删除；PUT 传 title、data、revision |

新建画布 revision 为 0；保存后使用响应中的新 revision。

## V1.5 动态能力与任务总结

- Tools 改为设置中的统一「允许智能体使用 Tools」开关；关闭时不向模型声明工具，服务端拒绝未授权调用。开启后模型按需调用 list_capabilities、load_skill、load_plugin，动态读取最新目录。插件加载仅在当前请求中生效，不修改全局启停状态，不执行第三方代码。
- @ 选择插件会加载到当前对话，无需全局启用。插件标签可移除；新建会话会清空选择。/ 仍可切换 Skill。动态 load_skill 会把完整提示词返回给当前模型。
- 新增 plugins/skill-creator，加载后注册 create_skill 工具，生成 skills/<id>/SKILL.md。写入受文件权限控制，none 拒绝，ask/read 请求确认，all 直接执行；提示词 ID 与路径仍校验。工具输出成功才报告已保存。每次任务最多 10 轮模型调用，每轮最多 8 个工具调用。
- 文件权限新增「全部允许」，在当前页面内跳过 data/files 与 Skill 写入确认；不授予项目外文件或任意命令访问。刷新后权限恢复关闭。
- 外观可调整主题色和强调色，浏览器本地保存，提供恢复默认。主题色影响艺术底图与暗色面板，强调色影响主要按钮、选中态与焦点。
- 工具与能力加载记录默认折叠，完成后绑定到对应助手回复，成为一条任务总结：耗时、工具次数、加载能力数量；展开查看细节。失败仍显示可展开的失败记录。摘要持久化随会话恢复。
- 上游若显式提供 reasoning_summary，会作为模型摘要折叠展示；不展示原始 reasoning_content，也不编造思考内容。没有摘要时仍显示实际工具和执行状态。

- 设置 → 常规 → 命令与轻量 Sandbox：默认禁止命令。受控模式启动独立 Python 工作进程，只实现 pwd/ls/cat/write/mkdir/cp/rm/grep/sha256/json/csv；不执行任意 Python、Shell 或网络请求。路径限定 data/files，校验绝对路径、越界与符号链接；读取最多 100 KB、写入最多 64 KB、输出最多 64 KB，命令超时 15 秒。它是受限命令解释器，不是容器、虚拟机或系统级隔离。

- 设置 → 本地记忆可开启对话后主动总结（默认开启、先询问）。普通流式对话和画布任务完成后额外调用当前模型一次，最多提炼两条稳定事实；收到有效 JSON 才候选保存。确认或自动保存后写入 memory/，更新记忆列表并记入折叠任务总结。不保存模型推测、密钥或临时请求的要求通过提炼提示词约束；记忆仍可人工检查和删除。关闭主动总结或将保存策略设为关闭可停用。
- 摘要调用最多等待 30 秒，失败不撤销已保存的回复。摘要与所有命令均有执行事件记录。本机命令、记忆保存与文件访问拥有独立权限，不互相暗中授权。

检查点采用内容寻址存储，位于 data/project-history，目录配置和记录位于 data/projects.sqlite3。快照跳过 .git、node_modules、.venv、venv、__pycache__、.cache、dist、build 和链接目录，限制为 10,000 文件、单文件 10 MB、合计 100 MB，超限会停止任务并提示。快照保留文件内容与普通权限，不记录空目录、ACL 或链接目标。嵌套目录的 AGENTS.md 目前需合入项目指令。

停止按钮取消普通流式对话任务并保留已接收内容，终止其正在运行的命令进程树，阻止后续工具调用。已写入文件可在项目变更中检查与回退。网络资源会尝试关闭，远端服务已经收到的请求可能继续计费，后台阻塞读取由接口超时收尾。独立终端仍由终端停止按钮控制。

回退逐文件执行并记录状态，异常时尝试恢复已应用文件。断电后的 applying 记录与回退前保护检查点保留，需人工检查后恢复。检查点当前保留历史版本，存储页单列占用。

## V2.3 便携环境、CLI 与语言资源

完整解压便携包到可写目录，运行 start.bat / 启动.bat 打开桌面，CLI.bat 打开交互终端。启动器优先使用 runtimes/python/python.exe，Node.js 和 npm 位于 runtimes/node，固定版 WebView2 位于 runtimes/webview2。运行时来源、版本与下载 SHA-256 记录在 runtimes/manifest.json。API 地址、密钥与模型由使用者配置。数据按原路径保存于 data/ 和 memory/。

便携包内含 CPython 3.14.8、pip 25.3、Node.js 24.22.2、npm 11.19.1 与 WebView2 156.0.4314.58 x64。Python 与 Node 工具会优先解析包内解释器；npm/npx MCP 命令直接使用包内 Node 执行对应入口。第三方 MCP 服务本身及用户另行安装的 Python/npm 包按各自配置提供，新增包的下载需要网络。

```bat
astra.bat doctor
astra.bat config --base-url https://api.example.com/v1 --model your-model --api-key-env ASTRA_API_KEY
astra.bat chat "Help me understand this project" --project G:\my-project
astra.bat chat --session SESSION_ID
astra.bat chat "List files" --permission trusted --json
astra.bat sessions
astra.bat serve --port 8787 --open
python.bat -m pip --version
node.bat --version
```

通过当前 Shell 的环境变量提供 API Key，避免把密钥写进命令历史。默认 CLI 权限为每次询问，非交互/JSON 模式自动拒绝审批请求。--permission full 显式开启完全访问。CLI 使用 GUI 相同的后台执行、工具、持久会话和项目检查点。Ctrl+C 请求停止当前任务，已发生的文件变更可在 GUI 检查与回退。CLI 自行启动的后台会随 CLI 退出清理；连接已有 GUI 服务时由桌面宿主管理后台。命令前可加 --data-dir PATH 使用单独的数据目录。

设置 → 常规 → 语言提供跟随系统、简体中文、English。默认跟随系统，切换立即生效并保存到 data/ui-preferences.json。同一服务的多个窗口同步语言设置。界面翻译独立于模型回复语言，用户消息、模型正文、编辑器内容、终端输出和版权原文保留原内容。

语言包放在 i18n/，也可在常规设置导入 JSON 或重新扫描。复制 en.json 并修改 code、name、locale、direction 和 messages 的值即可扩展语言，缺失条目显示源文案，支持 {0} 占位符。详见 i18n/README.md。自定义包导入会替换相同 code 的自定义包，内置语言的 code 受保护。无远程翻译调用。

设置 → 关于新增开源与第三方许可，展示版本、来源及原始许可文本。集中的版权记录位于 licenses/ 与 THIRD_PARTY_NOTICES.md，原始依赖的许可文件仍随依赖分发。AstraAgent 原创项目代码采用 MIT 协议，版权署名 cnxiaoy。第三方组件保留各自许可，详见 LICENSE、licenses/ 与 THIRD_PARTY_NOTICES.md。

Windows 10 首次桌面启动会按微软固定版 WebView2 部署要求，为包内 runtimes/webview2 目录配置应用容器读取与执行权限。许可与部署说明见 https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution 。请从本机磁盘运行便携包。


## V2.3.1 标准版与 Lite 版

两版提供相同的桌面、CLI、智能体工具、MCP、插件、记忆与界面功能。发行包不含使用者的 API 密钥、会话、记忆、自定义插件或自定义语言包。

| 版本 | 随包环境 | 本机要求 |
| --- | --- | --- |
| Standard 标准版 | Python、pip、Node.js、npm、固定版 WebView2 与应用依赖 | Windows x64 与系统 .NET Framework |
| Lite 精简版 | 应用代码、资源及必要的小型桌面/PDF依赖 | 标准 CPython 3.14 x64，桌面需系统 WebView2 与 .NET Framework |

Lite 使用 Python launcher 的 py -3.14 或 PATH 中的 python.exe，要求启用 GIL 的常规解释器，以匹配内置 cffi 扩展。无需额外 pip 安装桌面依赖。Node.js/npm 仅在 Node 工具或相应 MCP 服务需要时由本机提供。CLI 与浏览器模式无需桌面 WebView2，可运行 astra.bat serve --open。缺少 Python 时启动器会提供说明及官方下载地址。

两版均运行 start.bat / 启动.bat 打开桌面，CLI.bat 打开终端助手，astra.bat doctor 查看环境信息。CLI 默认每次询问权限。标准版的 doctor 检查包内完整环境，Lite 的 doctor 检查当前 CLI 环境并报告可选的 Node 及 WebView2 来源。Lite 的 doctor 成功不代表本机已安装桌面 WebView2。

关于页会显示发行版本类型，第三方许可清单按实际随包组件生成。每个包提供 RELEASE.md、release.json 和 SHA-256 文件。

维护者在完整源目录运行以下命令，同时生成两版。仅生成一个版本可用 --edition lite 或 --edition standard。Lite 包内也提供构建脚本，构建标准版时需先提供完整 runtimes 环境。

```bat
python.bat scripts\build_release.py --edition all --output G:\AstraAgent-releases
```

打包脚本采用应用文件与内置能力白名单，排除本地 data、用户 memory、自定义 Skills/插件、缓存、测试及开发日志。Lite 额外排除全部 runtimes 和对应的外部运行时版权副本，保留应用实际分发的许可文本。

## V2.4 统一能力管理与 OAuth

设置中的“插件与技能”合并插件、Skills、MCP、Tools 四个分类，提供搜索、统一开关、编辑与服务连接。独立 Skill 可以启停，通用助手始终保留，插件贡献的技能随插件管理。内置五个 Skill 与十四个插件补充了输入、执行、权限、证据和完成条件。

上下文压缩按有界分段递进合并，保留最近指令和完整工具调用/结果组。自动压缩仅在缩减有效时替换请求，失败时保留原上下文。会话摘要写入使用事务与原始消息快照校验，遇到并发编辑或删除会拒绝覆盖。原始对话和附件继续保存在本机。

服务商页面新增 OpenAI · ChatGPT OAuth。此版本按用户配置的正式 OAuth client ID 与 `http://127.0.0.1:端口/auth/callback` 发起浏览器授权，使用 PKCE S256、state 和 OIDC nonce，验证 RS256 身份签名、issuer、audience、有效期及账号身份。凭证仅保存在 `data/openai-oauth.dpapi`，通过当前 Windows 用户的 DPAPI 加密，临近过期时刷新。断开本机登录会清除本机凭证，远端授权可在 ChatGPT 的 Usage 设置管理。

登录成功后会出现独立的 OpenAI · ChatGPT OAuth 服务商。模型推理经过官方 `https://api.openai.com/v1/responses`，固定 `store=false`、`stream=true`，读取到完成事件才算成功。工具调用与现有 Agent 循环共用权限。模型目录由授权账户提供，实际可用性取决于该账户的授权、计划及额度。

使用者需提供为应用注册的 client ID 和允许的回调地址。当前发行未内置注册身份，真实 OpenAI 登录与付费模型推理需要使用者自行授权。自动化测试使用模拟授权与推理服务，覆盖 PKCE/state、真实 RSA 签名校验、DPAPI、流完成及工具转换。

官方接入文档 https://developers.openai.com/siwc/token-sharing-open-source/sign-in
官方模型接口文档 https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference

关于页的“点击查看开源声明”以弹窗集中显示项目 MIT 与所有随包第三方原文，鸣谢按用户指定文字列出作者和贡献者。


## V2.5 稳定输出与对话导航

普通流式对话在输入框旁提供“停止生成”，取消后保留已接收内容并关闭当前请求，刷新页面继续显示已保存的部分回复。请求尚未登记时停止按钮会等待当前请求注册并重试，避免误操作旧任务。多人格审查仍使用原有非流式请求流程。

生成期间只更新当前回复的轻量文本，保持历史消息节点与附件、按钮稳定；结束或停止后恢复完整 Markdown、代码和 LaTeX 渲染。向上阅读时保留当前位置，点击“回到最新”恢复跟随。

消息区的条纹导航根据可视高度合并采样，最多 120 条。悬停时邻近条纹渐变伸长并显示安全文本预览，点击或键盘确认可跳转消息。尊重系统减少动态效果设置。
